# T10 — Viewer: UI protokolu chyb — ✅ hotovo

## Co se udělalo
- **`src/ui/errorProtocolModal.ts`** (nový) — `showErrorProtocol(proto,
  sourceLabel?)`. Dynamicky staví modal (existující CSS třídy
  `modal-overlay`/`modal-dialog`/`modal-body`, bez zásahu do index.html):
  summary (celkem chyb DTI+ZPS) + sekce DTI a ZPS, v každé seznam kontrol
  (kód + skupina) a jejich chyb (popis + IDObjekt). Escape/klik mimo/křížek
  zavírá. Text přes `textContent` (bez XSS).
- **`fileUpload.ts`** — nový `JvfErrorProtocolCallback`; `loadJvfFile` i
  `loadSample` před parsem detekují `isErrorProtocolXml(xml)` → `parseErrorProtocol`
  → callback (report), místo mapových dat. `setupFileUpload` má nový volitelný
  param `onErrorProtocol`.
- **`dragDrop.ts`** — `setupDragAndDrop` prošel `onErrorProtocol` do `loadJvfFile`.
- **`main.ts`** — napojen `showErrorProtocol` jako `onErrorProtocol` pro upload
  i drag&drop.
- Fixture `public/fixtures/test_protokol_chyb.xml` (reálná ukázka protokolu).

## Ověření (jak otestováno + výsledek)
- `npm run typecheck -w jvf-viewer` + `npm run build` zelené.
- e2e: nový test „protokol chyb se zobrazí jako report modal" (obsahuje DTI,
  ZPS, „Volné konce linie", data se nenačtou jako vrstva); **celá e2e suite
  17/17 zelená** (chromium).
