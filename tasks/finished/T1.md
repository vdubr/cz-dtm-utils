# T1 — Registr verzí + sdílené typy — ✅ hotovo

## Co se udělalo
- `jvf_dtm_types/src/versions.ts`: `SUPPORTED_VERSIONS = ['1.4.3','1.5.0.1']`
  (aditivně), `DEFAULT_VERSION` ponechán `'1.4.3'` (R4 — auto-detekce řeší
  reálné 1.5.0.1 soubory). Doplněn komentář.
- `jvf_dtm_types/src/1.4.3/types.ts` (jen aditivně — R1):
  - `ObsahovaCast` += `'PSPI'` (změna #6).
  - Nové typy `RecordKind` (14 druhů: `Ins/Upd/Del`, `RefV/RefN`,
    `RefV*/RefN*`, `Pe*`), `RecordVisibility` (`public|nonpublic`),
    `RecordContext` (`input|refState|refChange|peer`) pro bezztrátový model
    záznamu (R2).
  - `ZaznamObjektu` += volitelné `recordKind?/visibility?/context?`
    (1.4.3 je nechává `undefined`, downstream se řídí `zapisObjektu`).
  - `TypDatoveSady` (= `number`) + konstanta `TYP_DATOVE_SADY_VYDEJ_PSPI = 11`
    (změna #10); `JvfDtm.typDatoveSady?`.
  - Model protokolu chyb (R5): `ProtokolChyba`, `ProtokolKontrola`,
    `ErrorProtocol { verze?, dti[], zps[] }`.
- `jvf_viewer/src/ui/versionSelect.ts`: oprava porovnání
  `SUPPORTED_VERSIONS.length === 1` (po přidání 2. verze TS zúžil `.length`
  na literál → type error). `as readonly string[]` odliterálování; runtime
  chování = select je při 2 verzích aktivní (naplňuje část T8).

## Ověření (jak otestováno + výsledek)
- `npm run build -w jvf-dtm-types` — zelený (tsc).
- `npm test` (parser 4500 testů + topology 214 testů) — vše zelené,
  1.4.3 beze změny (R1 splněno).
- `npm run typecheck` napříč všemi 4 balíčky — zelený (po opravě
  versionSelect.ts).

## Další kroky (pokud jsou potřeba)
- `TypDatoveSady` je zatím `number`; případné zpřesnění enumerace může přijít
  v T2 z distribučního XSD (nezávazné — kód se řídí jen kódem 11).
- Přesné field-names v `ProtokolChyba/Kontrola` se ověří v T6 proti reálné
  ukázce protokolu chyb (tvar `{dti[],zps[]}` je dle spec R5).
