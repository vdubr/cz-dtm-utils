# KMP-T1 — Auto-open panelu klikem (main.ts) — ✅ hotovo

## Co se udělalo
- **`main.ts`**: helper `ensureFeaturesPanelOpen()` (R1) — sjednocuje otevírací
  logiku s tlačítkem `btn-features` (mutual exclusion s error panelem,
  `showFeatures(currentObjekty)`, aktivace tlačítka).
- **2D handler** (`olMap.on('singleclick')`): odstraněna raná závora
  `if (!isFeaturesPanelVisible()) return;`; po `if (!picked) return;` se volá
  `ensureFeaturesPanelOpen()` před highlight + `selectFeatureInPanel` (R2/R3).
- **3D handler** (`three-canvas` click): ponechán guard `getIs3dActive()`,
  odstraněna panel-závora; po `if (!picked) return;` volá
  `ensureFeaturesPanelOpen()` (R2/R3). Highlight beze změny.
- `featuresPanel.ts` beze změny (R4).
- Fixture `public/fixtures/test_klik_plocha.xml` (jeden velký polygon).

## Ověření (jak otestováno + výsledek)
- `npm run typecheck -w jvf-viewer` + `npm run build` zelené.
- e2e „klik na prvek v mapě otevře zavřený panel Přehled prvků": se zavřeným
  panelem klik do středu mapy (na polygon) → panel se otevře, tlačítko
  aktivní, prvek vybraný (`.feature-row.active`). Celá suite **19/19 zelená**.
  (Pozn.: klik musí přijít až po vykreslení vrstvy — v testu čekání na
  `.layer-item` + krátká prodleva; OL `singleclick` je ~250 ms po pointerup.)
