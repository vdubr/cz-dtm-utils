# CP-T1 — Generátor ENUM_LABELS — ✅ hotovo

## Co se udělalo
- `jvf_parser/scripts/generate-types.ts`: nová funkce `generateEnumLabelsFile(enums)`
  → zapisuje `generated/enum-labels.ts` s
  `ENUM_LABELS: Record<string, Record<string, string>>`
  (vnější klíč = název číselníku `e.name`, vnitřní = kód `v.value` vč. `-3`,
  hodnota = český popisek `v.doc`). Escaping přes `JSON.stringify` (A4).
  Duplicitní `e.name` → `warn` + skip. Hodnoty bez popisku se přeskočí (A3).
- Zápis zaregistrován v `main()` vedle `enums.ts` → generuje se pro **každou
  verzi** spuštěním generátoru (A6): vygenerováno pro 1.4.3 i 1.5.0.1.

## Ověření (jak otestováno + výsledek)
- `npx tsx scripts/generate-types.ts 1.4.3` + `… 1.5.0.1` → vytvořily
  `src/{1.4.3,1.5.0.1}/generated/enum-labels.ts` (121 resp. 136 číselníků).
- Akceptace: `ENUM_LABELS.KategoriePozemniKomunikace["2"] === "dálnice II. třídy"`;
  `UrovenUmisteniObjektuZPS["-3"]` = „3. úroveň pod povrchem (nejníže)",
  `["0"]` = „na povrchu". Ověřeno v generovaném souboru.
- `npm run build` (types + parser) zelený; `npm test -w jvf-parser` **4533**
  zelených (regenerace 1.4.3 = jen 2řádkový cosmetic header diff v
  enums/entities, script je teď verzní).
