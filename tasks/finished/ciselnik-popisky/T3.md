# CP-T3 — Viewer: render s překladem — ✅ hotovo

## Co se udělalo
- **`featuresPanel.ts`**: `buildKVTable(entries, translate = false)` — při
  `translate` a existujícím popisku vypíše `String(v) + ' — ' + label`
  (`labelForAttribute(k, v, getActiveVersion())`), jinak holý `String(v)`.
  Verzně-vědomé (aktivní verze).
- Zapnuto **jen pro sekci „Atributy objektu"** (`buildKVTable(attrEntries, true)`);
  „Společné atributy" (`buildKVTable(commonEntries)`) zůstávají beze změny (A5).
- Import `labelForAttribute` z `jvf-parser` + `getActiveVersion` ze stavu.
- Fixture `public/fixtures/test_ciselnik.xml` — minimální osa PK
  (`KategoriePozemniKomunikace=2`).

  detail v „Atributy objektu" ukazuje **`2 — dálnice II. třídy`**;
