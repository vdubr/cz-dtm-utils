# CP-T2 — Veřejné API + testy — ✅ hotovo

## Co se udělalo
- **`src/1.4.3/index.ts`**: re-export `ENUM_LABELS` (§B).
- **`src/router.ts`** (vrstva verzního dispatche): `getEnumLabels(version)` +
  **verzně-vědomý** `labelForAttribute(attrName, value, version = DEFAULT_VERSION)`
  → `getEnumLabels(version)[attrName]?.[String(value)]` (A2/A3, `String(value)`
  sjednocuje číselný i řetězcový kód). Pokrývá i 1.5.0.1-specifické číselníky
  (PSPI) při `version='1.5.0.1'`.
- **`src/index.ts`**: export `getEnumLabels` + `labelForAttribute`.

## Ověření (jak otestováno + výsledek)
- `tests/1.4.3/entities/enum-labels.test.ts` (8 testů): unit
  (`KategoriePozemniKomunikace`→2, `UrovenUmisteniObjektuZPS`→0, číselný=řetězcový
  kód, neznámý→undefined, PSPI číselník jen pro 1.5.0.1), invariant
  (počet klíčů = počet enumů, každý enum má klíč, každý popisek neprázdný),
  pokrytí (klíčové atributy ve vzorcích 1.4.3 se všechny přeloží).
- `npm test -w jvf-parser`: **4541** zelených; `npm run build` + typecheck napříč
  balíčky zelené.
