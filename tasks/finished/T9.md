# T9 — Viewer: styly/legenda — ✅ hotovo (s dokumentovaným omezením)

## Co se udělalo
- **`symbology.ts`**:
  - `FALLBACK_COLORS` += `PSPI` (`#ab47bc`).
  - Přidáno **30 SYMBOLOGY entries pro nové typy 1.5.0.1** (9 DTM:
    0100000372/373/374/379/380/381/382/387/388 + 21 PSPI 0200000001–21).
    PSPI mají fialový čárkovaný obrys, ostatní barvu dle obsahové části.
- **`legendModal.ts`**: legenda je nově **verzně-vědomá** —
  `getEntityCatalog(getActiveVersion())` místo statického `ENTITY_CATALOG`;
  `CAST_ORDER` += `PSPI`. Pro 1.5.0.1 tak legenda ukáže PSPI i nové typy.
  Typ metadat odvozen z návratové hodnoty `getEntityCatalog` (širší, s PSPI).
- Legenda se renderuje při otevření → po auto-přepnutí verze (T8) ukáže
  správný katalog.

## Ověření (jak otestováno + výsledek)
- `npm run typecheck -w jvf-viewer` + `npm run build -w jvf-viewer` zelené.
- e2e: nový test „legenda po načtení 1.5.0.1 obsahuje sekci PSPI" zelený;
  **celá e2e suite 16/16 zelená** (chromium).

## Omezení / další kroky (dokumentováno)
- **Přesné kartografické styly a SVG symboly pro nové typy 1.5.0.1 nejsou
  z oficiálního Značkového klíče** — ten NENÍ součástí JVF distribuce
  (`JVF_DTM_1501.aspx` má jen xsd/model/doc). Původní 1.4.3 symbologie
  vznikla lokálním skriptem `extract_symbology.py`, který v repu není.
  Přidané styly jsou proto **provizorní** (odvozené z obsahové části),
  označené komentářem v `symbology.ts`. Po získání oficiálního Značkového
  klíče 1.5.0.1 (ČÚZK „Značkový klíč") je nahradit přesnými barvami + SVG.
  Nové typy tak **mají styl** (ne generický šedý fallback) a jsou v legendě
  správně kategorizované; jen konkrétní kartografie čeká na oficiální zdroj.
