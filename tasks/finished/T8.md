# T8 — Viewer: verzní routing + gate — ✅ hotovo

## Co se udělalo
- **`fileUpload.ts` `validateFileVersion`** — místo odmítnutí nesouladu verze
  nově: shoda → načíst; jiná **podporovaná** verze → `setActiveVersion`
  (auto-přepnutí) + načíst; nedeklarovaná verze → tolerovat (router už
  strukturně vyřešil); **nepodporovaná** verze → blokující modal + `false`.
- **`versionSelect.ts`** — subscribe na `onActiveVersionChange`, aby select
  reflektoval auto-přepnutí verze při načtení souboru. (Aktivace selectu při
  2 verzích už z T1.)
- **`activeVersion.ts`** — aktualizovaný doc (2 podporované verze, auto-switch).
- **Parser/topologie volání** už verzně-vědomé: `parseJvfDtm` (router, T5)
  detekuje verzi ze souboru; `runAllChecks(p.dtm)` (main.ts) odvozuje verzi
  z `dtm.verze` (T7) → 1501 páry pro 1.5.0.1 soubory. Beze změny v main.ts.
- **Fixtures/e2e**: přidán `public/fixtures/test_verze_1.5.0.1.xml` (reálná
  1.5.0.1 ukázka ZPS); `e2e/smoke.spec.ts` — test odmítnutí nepodporované
  `1.5.0` doladěn + nový test „1.5.0.1 se načte a aktivní verze se přepne"
  (selektor ukáže 1.5.0.1).
