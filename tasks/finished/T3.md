# T3 — Parser: záznamy + geometrie — ✅ hotovo

## Co se udělalo
Fork parserové vrstvy do `jvf_parser/src/1.5.0.1/` (1.4.3 beze změny, R1):
- **`records.ts`** — `RECORD_KIND_MAP` (14 druhů: Ins/Upd/Del, RefV/RefN,
  RefV{Ins,Upd,Del}, RefN{…}, Pe{Ins,Upd,Del}) → `{zapisObjektu, recordKind,
  visibility, context}` (R2, bezztrátové). `resolveRecordKind` s defenzivním
  fallbackem pro neznámé varianty. `isRecordElementName`.
- **`geometry.ts`** — `parseGeometrieObjektu1501`: wrappery
  `Bod2D/3D→pointProperty>Point`, `Linie2D/3D→curveProperty>LineString`,
  `Plocha2D/3D→Polygon` (přímo u ZPS / přes `surfaceProperty` u DTI/PSPI),
  `Obvod3D→LineString[]→MultiCurve`. Defenzivní `findPrimitive` (primitiv
  přímo i přes `*Property`, R6). GML primitivy reusovány z
  `../1.4.3/geometry-primitives.js` (sdíleno, ne kopírováno).
- **`attributes.ts`** — `parseAtributyObjektu1501` = 1.4.3 flatten + skupina
  `SpolecneAtributyObjektuPSPI`; low-level helpery z `../1.4.3/xml-helpers.js`.
- **`parser.ts`** — `parseJvfDtm1501`: iterace `ZaznamyObjektu` **po klíčích**
  (druh záznamu = název elementu), `isArray` pro `ZaznamObjektu*`; jinak
  struktura jako 1.4.3 (JVFDTM/DataJVFDTM/Data). Doprovodné info + TypDatoveSady
  přes seam `doprovodne-informace.ts` (stub — plná impl. v T4).

## Ověření (jak otestováno + výsledek)
- `tests/1.5.0.1/parser/records-geometry.test.ts` (10 testů) — parsuje
  `ukazkaZPS` (2× RefV, Polygon+MultiCurve, interior ring + 2 křivky),
  `ukazka_PSPI_import` (2× Ins, Polygon přes surfaceProperty, PSPI atributy),
  `ukazka_TI` (Point + LineString); RECORD_KIND_MAP bezztrátovost.

- `npm run build -w jvf-parser` zelený; dist/1.5.0.1 moduly vygenerovány.
