# BSL-T2 — Oprava 27 poškozených strokeWidth (RGB → fillColor) — ✅ hotovo

## Co se udělalo
- **`symbology.ts`**: všech **27** hodnot `strokeWidth: DDDDDDDDD.0` (9místné
  slepené RGB triplety, kam extrakce omylem uložila barvu výplně) převedeno
  zpět na `fillColor: '#rrggbb'` (rozklad 3×3 číslice, ověřeno každá složka
  ≤ 255). `strokeWidth` odstraněn → render použije rozumný default (1.5 px)
  místo monstrózního obrysu z `mmToPx(245245245)`.
- Provedeno programově (regex nad souborem, zachováno odsazení base i variant),
  s pojistkou na délku 9 a složky ≤ 255.

## Ověření (jak otestováno + výsledek)
- `grep -nE 'strokeWidth: [0-9]{7,}' symbology.ts` → **nic** (žádné poškozené).
- `npm run typecheck -w jvf-viewer` + `npm run build` zelené (žádný duplicitní
  `fillColor` klíč).
- Spot-check: `0100000051` příkop → `fillColor: "#f5f5f5"`; varianta „kašna"
  → `fillColor: "#d2d2d2"`. Dotčené objekty (příkop, manipulační plocha,
  nádrž, …) tak mají světlou výplň a tenký obrys místo obří čáry.
