# BSL-T1 — Reprezentativní barva v legendě a panelu — ✅ hotovo

## Co se udělalo
- **`jvfLayers.ts`**: nový export `resolveRepresentativeStyle(ot)` — když base
  symbologie nemá `fillColor` ani `strokeColor`, ale barvu nese některá
  varianta, vezme se barva z **první varianty s barvou**
  (`sym.variants.find(v => v.fillColor ?? v.strokeColor)`); jinak = `resolveStyle`.
  Fallback na `FALLBACK_COLORS[obsahovaCast]` až když barvu nemá ani varianta.
- **`legendModal.ts`** + **`layerPanel.ts`**: swatch přes
  `resolveRepresentativeStyle` místo base-only `resolveStyle`.

## Ověření (jak otestováno + výsledek)
- `npm run typecheck -w jvf-viewer` + `npm run build` zelené.
- e2e „legenda ukazuje reprezentativní barvu sítě z variant (elektro červená)":
  po filtru „trasa elektrické sítě" má swatch **`#e60000`** (červená z variant),
  ne oranžový TI fallback `#ff9800` (ten zůstává jen barvou hlavičky obsahové
  části). Celá suite **20/20 zelená**.
- Ověřeno reálným renderem: swatch = `<line stroke="#e60000">` (shoda s mapou),
  plyn/voda/kanalizace/teplovod tak dostanou své barvy z variant místo jednotné
  `#ff9800`.
